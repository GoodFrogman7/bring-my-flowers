📱 STEP 1: START NGROK (if not already running)
----------------------------------------------------------------------------------------

Open a NEW PowerShell window and run:

    ngrok http 3000

You'll see output like:

    Session Status    online
    Forwarding        https://abc123-xyz-456.ngrok-free.app -> http://localhost:3000

COPY THE HTTPS URL (the one ending in .ngrok-free.app or .ngrok.io)
Example: https://abc123-xyz-456.ngrok-free.app

----------------------------------------------------------------------------------------
📲 STEP 2: JOIN WHATSAPP SANDBOX
----------------------------------------------------------------------------------------

1. Open Twilio Console: https://console.twilio.com/us1/develop/sms/try-it-out/whatsapp-learn

2. You'll see instructions like:
   "Send this message to join: join <your-code-here>"
   "WhatsApp number: +1 415 523 8886"

3. From YOUR PHONE, send that message to activate sandbox

----------------------------------------------------------------------------------------
🔗 STEP 3: SET WEBHOOK IN TWILIO
----------------------------------------------------------------------------------------

1. Go to: https://console.twilio.com/us1/develop/sms/settings/whatsapp-sandbox

2. In "When a message comes in" field, paste:
   
   YOUR_NGROK_URL/webhook/whatsapp
   
   Example: https://abc123-xyz-456.ngrok-free.app/webhook/whatsapp

3. Method: POST

4. Click SAVE

========================================================================================
📞 TROUBLESHOOTING
========================================================================================

If messages not arriving:
- Make sure ngrok is running (check the PowerShell window)
- Verify webhook URL in Twilio has /webhook/whatsapp at the end
- Confirm you joined the sandbox (sent the join message)
- Check ngrok web interface: http://localhost:4040

If bot not responding:
- Check the bot terminal for errors
- Verify Ollama is running (it is, we tested it)
- Look at ngrok requests at http://localhost:4040
